# Dashboard Page

## 概述
现代化的可视化数据看板，采用简约扁平设计风格，与应用整体配色方案保持一致。

## 功能模块

### 1. 支出环比 (Month-over-Month Comparison)
- **功能**: 显示本月与上月的支出对比
- **数据展示**:
  - 本月总支出金额
  - 环比变化百分比（带涨跌箭头指示）
  - 上月支出金额
- **视觉设计**: 
  - 卡片式布局
  - 金黄色图标（趋势向上）
  - 涨跌用不同颜色标识（红色=增加，绿色=减少）

### 2. 预算进度 (Budget Progress)
- **功能**: 显示月度预算使用情况
- **数据展示**:
  - 预算使用进度条（带百分比）
  - 已用金额
  - 剩余金额
  - 日均可用金额（基于剩余天数计算）
- **视觉设计**:
  - 渐变色进度条（根据使用比例变色）
  - 三个信息卡片展示详细数据
  - 粉红色图标（钱包）

### 3. 支出折线图 (Expense Trend Chart)
- **功能**: 展示近7天的支出趋势
- **数据展示**:
  - 日期（横坐标）
  - 支出金额（纵坐标）
  - 平滑曲线连接
  - 渐变填充区域
- **视觉设计**:
  - 蓝色主题
  - 圆点标记每日数据
  - 渐变阴影区域增强视觉效果

### 4. 支出类型饼状图 (Category Distribution)
- **功能**: 按类型展示支出分布
- **数据展示**:
  - 饼状图显示占比
  - 右侧列表显示详细金额
  - 按金额从高到低排序
- **视觉设计**:
  - 圆环饼图
  - 不同类型使用不同颜色
  - 百分比标签
  - 紫色图标（饼图）

## 技术特点

### 1. 响应式设计
- 使用 `Obx()` 实现响应式数据更新
- 数据变化时自动刷新UI

### 2. 模块化组件
- 每个模块都是独立的 Widget
- 便于维护和扩展

### 3. 颜色系统
- 使用应用统一的 `AppColors`
- 不同模块使用特定主题色：
  - 环比: 金黄色
  - 预算: 粉红色
  - 折线图: 蓝色
  - 饼图: 紫色

### 4. 图表库
- 使用 `fl_chart` 库绘制专业图表
- 支持动画和交互

## 数据计算

### 环比计算
```dart
changePercentage = (currentMonth - lastMonth) / lastMonth * 100
```

### 日均可用预算
```dart
dailyBudget = (budget - spent) / remainingDays
```

### 趋势数据
- 获取近7天的每日支出数据
- 自动填充缺失日期（金额为0）

### 分类统计
- 按消费类型聚合金额
- 计算占比并排序

## 使用方式

在 `home_page.dart` 中引入：
```dart
import '../pages/dashboard/dashboard_page.dart';

static final List<Widget> pages = [
  const ExpenseListPage(),
  const DashboardPage(), // 替代原 ExpenseChartPage
];
```

## 依赖项

- `flutter/material.dart` - UI框架

- `fl_chart` - 图表库
- `ExpenseController` - 数据控制器
